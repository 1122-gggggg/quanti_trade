# Phase 2 Acceptance Criteria

- Users can create and save 1–16 chart layouts.
- Symbol, interval, crosshair, time range and drawings can be synchronized independently.
- Charts support multiple panes and price scales.
- Drawing objects are interactive, persistent, searchable and template-aware.
- Standard and non-standard chart calculations have golden tests.
- Large histories are streamed or downsampled without freezing the UI.
- Layout changes synchronize safely across browser tabs and devices.

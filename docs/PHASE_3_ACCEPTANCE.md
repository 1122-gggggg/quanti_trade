# Phase 3 Acceptance Criteria

- User strategies run in an isolated, deterministic runtime.
- Editor diagnostics and autocomplete use the same versioned language specification as workers.
- Multi-symbol and multi-timeframe data requests are bounded and reproducible.
- Portfolio backtests support long/short, margin, orders, costs and corporate actions.
- Optimization, walk-forward and Monte Carlo jobs are cancellable and auditable.
- Custom scripts can produce chart plots, alerts and screener columns from one runtime.

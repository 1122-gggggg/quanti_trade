# Platform Status

Current state: correctness-focused browser prototype.

Implemented foundations include standard chart series, canonical timeframes, deterministic Heikin-Ashi conversion, corrected candle rollover, normalized data-provider contracts, improved single-asset backtesting, and corrected leveraged paper-account accounting.

The product is not yet a TradingView-equivalent service because it lacks a backend, licensed multi-market history, user accounts, server-side alerts, multi-chart layouts, a sandboxed strategy language, durable trading execution, and community infrastructure.

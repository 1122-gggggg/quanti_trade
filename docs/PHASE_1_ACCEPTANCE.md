# Phase 1 Acceptance Criteria

- Users can sign in and save layouts, watchlists and strategies.
- Historical bars are supplied by an attributed provider or user import.
- Instrument metadata includes venue, currency, timezone and session.
- Backtests execute asynchronously and persist immutable run manifests.
- Saved results identify data source, date range, adjustment mode, fees and slippage.
- Bar replay reveals no future bars to indicators or strategies.
- Price and indicator alerts continue when the browser is closed.
- CI includes type checks, lint, unit tests and integration tests.

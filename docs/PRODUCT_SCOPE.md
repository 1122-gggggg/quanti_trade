# Product Scope

## Goal

Build an independent multi-asset charting, research, backtesting and trading platform with functionality comparable to major professional charting terminals.

## Included

- Charting and drawing workflows
- Indicators and custom strategy execution
- Historical replay and backtesting
- Screeners, alerts, watchlists and research tools
- Paper trading and approved broker integrations
- User workspaces and community publishing

## Excluded from direct copying

- TradingView trademarks, visual identity and copyrighted content
- Proprietary source code or undocumented internal behavior
- Pine Script implementation or private compiler/runtime code
- Community scripts, ideas or user data without permission
- Exchange, news, fundamental or broker data without licenses

Equivalent capabilities must be developed from public specifications, documented financial conventions and independently designed APIs.
